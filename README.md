# 👷 Smart PPE Detection System (AI for Safety)

## 📌 Project Overview
An End-to-End Artificial Intelligence web application designed to automatically detect Personal Protective Equipment (PPE) compliance. This project was built to align with the rigorous safety standards and smart city initiatives . 

## 🚀 Live Demo
**[Click Here to Test the AI Web App Live!]([https://turki-safety-ai-ndbqfxbf6tysvlt4rhciha.streamlit.app/])**

## 🛠️ Tech Stack & Tools
* **Computer Vision Model:** YOLOv8 (Ultralytics)
* **Image Processing:** OpenCV, NumPy, Pillow
* **Web Framework & Deployment:** Streamlit Community Cloud
* **Language:** Python

## ✨ Key Features
* **Custom Object Detection:** Fine-tuned to detect Helmets and Reflective Vests.
* **Smart Alerting System:** Dynamically draws **Green** bounding boxes for compliant workers and **Red** bounding boxes for missing safety equipment.
* **Interactive UI:** A seamless web interface allowing users to upload images and receive instant, visualized AI analysis.

## 🧠 Model Training Details
The model was trained using a custom dataset of construction workers, focusing on minimizing false positives and optimizing inference speed for real-time applications.
